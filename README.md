# Grivini NTN Lab v5.1

Complete static website package.

## Pages
- `/` — Home
- `/labs/` — NTN Lab product page
- `/labs/app/` — NTN Lab application
- `/docs/` — Documentation
- `/about/`
- `/contact/`

## Deployment
Replace the repository contents with this package, commit to `main`, and allow Vercel to redeploy.

## Scope
This package contains only the current public NTN Lab. It does not include luxury, music, future labs, roadmap, or unreleased product plans.

## Runtime
CesiumJS and online map content require an internet connection.
