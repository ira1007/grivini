# Grivini Website Starter

Static website structure:

- `/` — Grivini homepage
- `/labs/` — Grivini Labs
- `/labs/ntn-orbit/` — NTN Orbit tool page
- `/about/`
- `/contact/`

## Deployment

Upload all files and folders to the root of the Grivini GitHub repository.
Vercel can deploy this project without a framework or build command.
