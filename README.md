# Grivini NTN Orbit Website v5.0

Complete static website package.

## Upload
Delete the existing repository contents, then upload all files and folders from this package to the repository root and commit to `main`.

## URLs
- `/` — Grivini homepage
- `/labs/` — NTN Orbit application (direct, no iframe)
- `/labs/ntn/` — redirects to `/labs/`
- `/about/`
- `/contact/`

No luxury, music, roadmap, future labs, or unreleased plans are included.
CesiumJS and map content require an internet connection.
