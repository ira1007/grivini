Getting started

This preview accepts SIB19-style position and velocity inputs and visualizes satellite motion relative to a selected UE location.

  • 1. Open NTN Lab: Launch the application from the NTN Lab page.
  • 2. Load the demo: Use the preloaded Cupertino UE and two SIB19 satellites.
  • 3. Review inputs: Confirm raw RTD values and input format.
  • 4. Start playback: Use Play, Pause, timeline, and speed controls.
  • 5. Inspect metrics: Compare elevation, azimuth, range, delay, RTT, and Doppler.

Preview notice: Engineering calculations and test scenarios should be independently validated before use in formal test planning.
